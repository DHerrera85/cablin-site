# Cablín - Sitio Web

Proyecto web desarrollado en **HTML**, **CSS** y **JavaScript** para presentar contenido multimedia, secciones destacadas y un selector interactivo de personajes.

## 📂 Estructura del Proyecto

- **`index.html`**
  - Documento principal que define la estructura del sitio.
  - Contiene:
    - **Encabezado** con logotipo.
    - **Banner superior** con mensaje animado.
    - **Carrusel de bumpers**.
    - **Sección de categorías**.
    - **Destacados de la semana**.
    - **Selector de personajes** con imágenes miniatura y verticales laterales.
    - **Pie de página**.

- **`styles.css`**
  - Estilos visuales del sitio.
  - Incluye:
    - Definición de colores y tipografía (`Fredoka`).
    - Diseño adaptable para escritorio y móvil.
    - Estilos del carrusel, categorías y destacados.
    - Estética del selector de personajes y borde activo al seleccionar.
    - Reglas `@media` para comportamiento responsive.

- **`script.js`**
  - Funcionalidad dinámica.
  - Implementa:
    - Navegación del carrusel.
    - Control de selección de personaje con opción de enviar a lado izquierdo o derecho.
    - Activación de borde visual en miniaturas seleccionadas.
    - Desplazamiento horizontal de miniaturas en móviles.

## 📱 Adaptabilidad

- **Escritorio**: Distribución completa con imágenes verticales a ambos lados y miniaturas organizadas en filas.
- **Móvil**: Miniaturas desplazables horizontalmente y logotipo centrado.

## ⚙️ Tecnologías

- **HTML5**
- **CSS3** con `flexbox` y `@media queries`
- **JavaScript** vanilla (sin dependencias externas)
- Tipografía **Google Fonts**: `Fredoka`
